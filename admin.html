GitHub सेटिंग

इसी जानकारी से एडमिन पैनल आपके रिपॉज़िटरी में बदलाव भेजेगा। टोकन केवल आपके ब्राउज़र में रहता है।

टोकन बनाना: GitHub → Settings → Developer settings → Fine-grained tokens। केवल इसी रिपॉज़िटरी का चयन करें और Contents को “Read and write” दें।
