# श्रीराम वैदिक ज्योतिष केंद्र: वेबसाइट + एडमिन पैनल

यह एक स्थिर (static) वेबसाइट है, जिसे **GitHub Pages पर मुफ़्त** चलाया जा सकता है। किसी सर्वर या डेटाबेस की ज़रूरत नहीं है।
साइट की **सारी सामग्री एक ही फ़ाइल `data/content.js` में** रहती है, और उसे बदलने के लिए **`admin.html` (एडमिन पैनल)** है।

## फ़ाइलें

| फ़ाइल | काम |
|---|---|
| `index.html` | साइट का पेज |
| `admin.html` | एडमिन पैनल (यहाँ से सब कुछ बदलें) |
| `data/content.js` | साइट की पूरी सामग्री, रंग, मेन्यू (एडमिन पैनल इसे अपने आप लिखता है) |
| `images/` | तस्वीरें |
| `assets/panchang.js` | पंचांग की पूरी गणना (सूर्य-चंद्र की स्थिति, तिथि, मुहूर्त, पर्व) |
| `assets/` | डिज़ाइन और बाक़ी कोड |
| `serve.py`, `start-admin.bat`, `start-admin.sh` | कंप्यूटर पर लोकल एडमिन चलाने के लिए |

## पंचांग, राशिफल और मुहूर्त कैसे बनते हैं

ये किसी बाहरी वेबसाइट या API से नहीं आते। साइट खुद, आगंतुक के फ़ोन या कंप्यूटर में ही, सूर्य और
चंद्रमा की स्थिति की गणना करके बनाती है। इसलिए न कोई key चाहिए, न कोई सर्वर, न किसी और सेवा के
बंद होने का डर। यह आने वाले वर्षों में भी अपने आप चलता रहेगा।

- **गणना का आधार**: दृक् सिद्धांत, लाहिड़ी (चित्रपक्ष) अयनांश। सूर्य-चंद्र की स्थिति के लिए मानक
  खगोलीय सूत्र (Meeus) प्रयुक्त हैं। चंद्रमा की स्थिति की शुद्धता लगभग 1 arcsecond तक जाँची गई है।
- **जो अपने आप बनता है**: तिथि, वार, नक्षत्र, योग, करण, मास, पक्ष, ऋतु, संवत, संवत्सर,
  सूर्योदय-सूर्यास्त, चंद्रोदय-चंद्रास्त, राहु काल, यमगण्ड, गुलिक काल, अभिजित, दुर मुहूर्त,
  दिन-रात के चौघड़िया, होरा, लग्न सारणी, चंद्र गोचर और व्रत-त्यौहार की तिथियाँ।
- **सूर्योदय की पद्धति**: डिफ़ॉल्ट रूप से हिन्दू परंपरा (सूर्य-बिंब का मध्य भाग क्षितिज पार करे)।
  एडमिन में दूसरी पद्धति भी चुनी जा सकती है। दोनों में 1-2 मिनट का अंतर आता है।
- **नगर**: एडमिन में नगरों की सूची है (अक्षांश-देशांतर सहित)। आगंतुक “मेरा स्थान” दबाकर अपनी
  जगह के अनुसार भी देख सकते हैं।
- **पंचांग की तस्वीर**: “पंचांग की तस्वीर बनाएँ” दबाने पर 1080×1350 की तस्वीर बनती है, जिसे
  डाउनलोड करके या सीधे WhatsApp स्टेटस पर भेजा जा सकता है।

### ध्यान देने योग्य बातें

- कुछ पर्वों की तिथि प्रदोष, निशीथ या चंद्रोदय काल के नियमों से तय होती है, और क्षेत्रीय पंचांगों
  में एक दिन का अंतर आ सकता है। आयोजन से पहले अपने स्थानीय पंचांग से मिला लेना उचित है।
  अपने आयोजन एडमिन के “व्रत एवं त्यौहार → अपने पर्व” में जोड़े जा सकते हैं।
- **राशिफल** चंद्र गोचर (चंद्रमा जन्म राशि से किस भाव में है) पर आधारित सामान्य संकेत देता है।
  हर राशि के लिए आचार्य जी अपना संदेश एडमिन में लिख सकते हैं — वही संदेश साइट पर दिखेगा।
  यहाँ कोई मनगढ़ंत भविष्यवाणी अपने आप नहीं बनती।
- **दुर मुहूर्त** के नियम क्षेत्र के अनुसार थोड़े अलग होते हैं; यहाँ प्रचलित परंपरा ली गई है।

## 1. GitHub पर साइट डालना (एक बार का काम)

1. github.com पर खाता बनाएँ, फिर **New repository** दबाएँ। नाम रखें जैसे `shriram-jyotish`, **Public** चुनें, **Create repository**।
2. नए रिपॉज़िटरी में **uploading an existing file** पर क्लिक करें। इस ज़िप के अंदर की **सारी फ़ाइलें और फ़ोल्डर** खींचकर डालें (`.nojekyll` फ़ाइल समेत), फिर **Commit changes**।
3. **Settings → Pages** में जाएँ। **Source: Deploy from a branch**, **Branch: main** और **/(root)** चुनकर **Save** करें।
4. 1-2 मिनट बाद साइट इस पते पर चालू होगी:
   `https://आपका-यूज़रनेम.github.io/shriram-jyotish/`
5. एडमिन पैनल का पता: `https://आपका-यूज़रनेम.github.io/shriram-jyotish/admin.html`

अपना डोमेन (जैसे `shriramjyotish.in`) जोड़ना हो तो **Settings → Pages → Custom domain** में डालें।

## 2. एडमिन पैनल से बदलाव करना

एडमिन पैनल में बाईं ओर हर भाग की सूची है और दाईं ओर साइट का **लाइव पूर्वावलोकन** दिखता है। आप बदल सकते हैं:

- साइट का नाम, नंबर, WhatsApp नंबर, फ़ुटर, घोषणा पट्टी, सोशल लिंक
- **रंग**: रात और दिन की थीम के सभी रंग
- **मेन्यू**: नाम, क्रम, किसी भाग को छिपाना या दिखाना
- हर सेक्शन का पाठ, सूचियाँ, पूजाएँ, कथाएँ, ग्रह-दोष के टैब, करियर की पंक्तियाँ
- **तस्वीरें**: आचार्य जी की फोटो, गैलरी की तस्वीरें (अपने आप छोटी और हल्की बन जाती हैं)
- **नए पेज / सेक्शन** जोड़ना
- पाठ में `**शब्द**` लिखने पर वह मोटे अक्षरों में दिखता है

बदलाव को साइट पर पहुँचाने के **तीन तरीके** हैं:

### तरीका A: कंप्यूटर पर लोकल सर्वर (सबसे आसान)

1. पूरा फ़ोल्डर अपने कंप्यूटर पर रखें। Python इंस्टॉल हो (python.org)।
2. **Windows:** `start-admin.bat` पर दो बार क्लिक करें। **Mac/Linux:** टर्मिनल में `sh start-admin.sh`।
3. ब्राउज़र में एडमिन पैनल खुलेगा। ऊपर हरे रंग में “लोकल सर्वर चालू” दिखेगा।
4. बदलाव करें, **सेव करें** दबाएँ। यह सीधे फ़ाइलों में लिख देगा (`Ctrl+S` भी चलता है)।
5. GitHub पर भेजने के लिए **git push** बटन दबाएँ।

`git push` बटन तभी चलेगा जब फ़ोल्डर GitHub से जुड़ा हो। उसके लिए एक बार टर्मिनल में:

```
git clone https://github.com/आपका-यूज़रनेम/shriram-jyotish.git
```

फिर ज़िप की फ़ाइलें उस `shriram-jyotish` फ़ोल्डर में डालकर उसी फ़ोल्डर में `serve.py` चलाएँ। (GitHub Desktop ऐप भी उपयोग कर सकते हैं।)

### तरीका B: सीधे GitHub पर प्रकाशित करना (किसी भी कंप्यूटर/फ़ोन से)

1. GitHub पर टोकन बनाएँ: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**।
   - Repository access: **Only select repositories** → अपना रिपॉज़िटरी
   - Permissions → **Contents: Read and write**
2. एडमिन पैनल में ऊपर **⚙** दबाएँ। यूज़रनेम, रिपॉज़िटरी का नाम, ब्रांच (`main`) और टोकन भरें।
3. बदलाव के बाद **GitHub पर प्रकाशित करें** दबाएँ। 1-2 मिनट में साइट अपडेट हो जाएगी।
4. किसी दूसरे कंप्यूटर पर ताज़ा सामग्री लेने के लिए **GitHub से लाएँ** दबाएँ।

### तरीका C: फ़ाइल डाउनलोड

अगर A और B उपलब्ध न हों, तो **सेव करें** दबाने पर `content.js` और तस्वीरें डाउनलोड होंगी। उन्हें `data/` और `images/` में रखकर GitHub पर अपलोड कर दें।

## सुरक्षा, ज़रूर पढ़ें

- **टोकन किसी को न दें।** वह पासवर्ड जैसा है। एडमिन पैनल उसे केवल आपके ब्राउज़र में रखता है और सिर्फ़ `api.github.com` को भेजता है।
- GitHub Pages पर `admin.html` सबको खुलता दिखेगा, पर **टोकन के बिना कोई भी बदलाव प्रकाशित नहीं कर सकता**। साइट में बदलाव की असली चाबी आपका टोकन और GitHub खाता है।
- अगर आप एडमिन पेज सार्वजनिक नहीं रखना चाहते, तो `admin.html` को रिपॉज़िटरी से हटा दें और केवल अपने कंप्यूटर पर रखें (तरीका A से चलाएँ)।
- फ़ोन खोया या टोकन लीक हुआ तो GitHub में टोकन तुरंत **Revoke** कर दें।
- हर प्रकाशन GitHub में इतिहास के साथ सुरक्षित रहता है, इसलिए गलती होने पर पुराना संस्करण लौटाया जा सकता है।
